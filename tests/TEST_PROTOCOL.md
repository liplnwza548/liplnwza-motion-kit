# Cross-agent test protocol

รอบ 1 — ใช้แพ็ก release เดียวกัน เนื้อหา/เสียง/ภาพเดียวกัน examples/benchmark15 เริ่มใหม่ทุกตัวและเลือก output directory ที่ไม่มีผลเก่าปน อย่าใช้ video.mp4 ที่แนบเป็นหลักฐานว่า agent เรนเดอร์เอง เก็บ log/เวลา/sha ใหม่

คำสั่งสำหรับผู้ใช้คัดลอก:
> อ่าน START_HERE.md ในแพ็ก ตรวจความสามารถ แล้วเรนเดอร์ examples/benchmark15/job.json ไปยัง jobs/test-ชื่อAI/output เก็บคำสั่งและผลตรวจจริง ถ้าขั้นไหนทำไม่ได้ให้ระบุ ห้ามแก้บท เสียง หรือสไตล์เพื่อทำให้ทดสอบง่ายขึ้น ส่ง MP4 และสรุปว่าใช้เวลา ค่าใช้จ่าย และฉันต้องช่วยอะไรบ้าง

ผ่านเมื่อ: doctor ผ่าน, เตรียมไฟล์ครบ, render เป็น MP4 จริงจากคำสั่ง, QC ผ่าน, ภาพ/เสียง/ซับไม่เสีย และไม่มีขั้นช่วยมือที่ซ่อนอยู่ หากต้องติดตั้งให้บันทึก เวลา setup แยกจากเวลา render ห้ามคิดค่าบริการแฝงเอง

รอบ 2 — เฉพาะ 2 ตัวที่ผ่านดีสุด ใช้เนื้อหาใหม่เดียวกัน ความยาว30–60s และแหล่งข้อมูลเดียวกัน ให้เสนอแนวทางก่อน Philip อนุมัติของแต่ละตัว แล้วผลิตจนส่งมอบ งานใหม่ต้องไม่สืบทอดการอนุมัติ benchmark

ให้คะแนน 0–5: ความถูกต้อง, คุณภาพภาพ, เสียง/ซับ/ปาก, ทำจบได้เอง, แก้ง่าย ควบคู่เวลารอจริง เวลาเจ้าของช่วย จำนวนครั้งที่ต้องแก้ และต้นทุนจริง อย่าเลือกจากคะแนนรวมอย่างเดียวหากมีข้อเท็จจริงหรือสิทธิ์ผิด

สถานะ read-only/planning-only เป็นผลทดสอบความสามารถ ไม่ใช่ render pass เลือกตัวหลักหลังมีหลักฐาน และอาจเก็บตัวอื่นเป็นผู้วิจัย/ตรวจทานได้
