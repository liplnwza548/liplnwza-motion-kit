# Runtime bridge

Native skill installs only instructions. Full Motion Kit lives in the owner folder:
https://drive.google.com/drive/folders/1sbnVgJ-w9AfzKlm35wJQXO-vhJPSCRK5

Download and extract the release ZIP as a whole; keep assets/renderer/references together. Set LIP_MOTION_ROOT to the extracted directory, or explicitly open it as the workspace. Run scripts/locate_kit.py PATH to verify the two entrypoint files; then follow START_HERE.md. Never claim installation grants shell, network, Drive access or video rendering.
