# คู่มือแหล่งสื่อและสิทธิ์

คู่มือปฏิบัติสำหรับ agent ที่สร้างงานด้วย Motion Kit สรุปจาก `~/workspace/free-assets/asset-sources.md` (34 แหล่ง, 9 หมวด; ตรวจโหลดจริงในต้นทาง) และเงื่อนไขที่ระบุในหน้าสิทธิ์ของแหล่งต่าง ๆ เอกสารนี้เป็นจุดเริ่มต้นค้นหา ไม่ใช่ใบอนุญาตครอบคลุมทุกไฟล์: ตรวจหน้าของไฟล์นั้นและเงื่อนไขล่าสุดก่อนใช้ทุกครั้ง

## กฎสิทธิ์บังคับของโปรเจกต์

1. **โหลดตามงานเท่านั้น:** เลือกไฟล์เมื่อมี job ที่จะใช้จริง ห้ามโหลดสะสมหรือทำคลัง stock ส่วนตัวใน repo
2. **บันทึกที่มาทุกไฟล์:** ทุกไฟล์ที่ดาวน์โหลดต้องมีรายการใน `media/_ที่มา.txt` ระบุชื่อไฟล์, ลิงก์ตรงไปยังรายการ, ชื่อผู้สร้าง, license/เงื่อนไขจริง, การใช้งานที่อนุญาต และวันที่ตรวจสิทธิ์ หากเว็บระบุเครดิตหรือข้อจำกัด ให้บันทึกข้อความที่ต้องทำตามด้วย
3. **ตรวจการใช้จริงก่อนใช้:** ตรวจเงื่อนไขของไฟล์ทุกไฟล์ให้ครอบคลุมวิดีโอเชิงพาณิชย์/การเผยแพร่, การดัดแปลง, attribution, การฝึก AI, Content ID, บุคคล/เครื่องหมายการค้า และการแจกจ่ายไฟล์ต้นฉบับ เลือกใช้ได้เมื่อเงื่อนไขอนุญาตการใช้งานของ job นั้นเท่านั้น
4. **AI-generated ก็ต้องบันทึก:** ระบุผู้เขียน prompt, เครื่องมือ/ผู้ให้บริการและรุ่น, วันที่สร้าง, prompt หรือที่เก็บ prompt, เงื่อนไขบริการที่ตรวจ และข้อจำกัดของ output ใน `_ที่มา.txt` อย่าระบุว่าเป็นภาพถ่ายหรือหลักฐานจริง
5. **ลงทะเบียนใน `job.json`:** media ทุกชิ้นในทุก scene ต้องมี `kind` (`image`/`video`), `role`, `label` ที่มองเห็นในฉาก และ `source_id`; `source_id` ต้องตรงกับ `id` ใน `sources` และทุก source ต้องมี `id`, `origin`, `creator`, `license`, `usage`, `checked_date` ครบตาม `renderer/kit.py validate`
6. **แสดงที่มาในฉาก:** ใส่ชื่อผู้สร้าง/เว็บหรือที่มาที่เหมาะสมไว้ใน `media.label` ทุกฉากที่ใช้สื่อ แม้ license ของแหล่งนั้นไม่บังคับเครดิต เพราะเป็นกฎของ kit
7. **คงหลักฐานกับไฟล์:** เก็บ license/notice ที่ไฟล์ต้องพกติดไว้ตามข้อกำหนดของมัน อย่าเผยแพร่หรือแยกขายไฟล์ต้นฉบับ เว้นแต่ license อนุญาตชัดเจน

ตัวอย่างโครงสร้าง media:

```json
{
  "path": "media/example.mp4",
  "kind": "video",
  "role": "illustration",
  "label": "ฟุตเทจ: ชื่อผู้สร้าง / ชื่อแหล่ง",
  "source_id": "example-video"
}
```

## ตัวอย่างเงื่อนไขที่ตรวจแล้วสำหรับตัวอย่างใน kit

- [Pexels: Traveling Through the City](https://www.pexels.com/video/traveling-through-the-city-5129233/) โดย Joseph Eulo แสดง license เป็น Free; หน้าสิทธิ์ Pexels อนุญาตใช้และดัดแปลงฟรีโดยไม่บังคับเครดิต แต่ห้ามขายสำเนาที่ไม่ดัดแปลง, แจกจ่ายต่อบนคลัง stock อื่น หรือสื่อว่าบุคคล/แบรนด์รับรองสินค้า ตรวจซ้ำก่อนดาวน์โหลดหรือเผยแพร่
- [OpenAI Terms of Use](https://openai.com/policies/terms-of-use/) ระบุว่าระหว่างผู้ใช้กับ OpenAI ผู้ใช้เป็นเจ้าของ output ภายใต้กฎหมายและเงื่อนไขที่เกี่ยวข้อง output อาจไม่เป็นเอกลักษณ์และต้องตรวจความเหมาะสมเอง ข้อมูลนี้ไม่ใช่ public license หรือคำรับรองว่าทุก output ใช้ได้โดยไม่มีข้อจำกัด
