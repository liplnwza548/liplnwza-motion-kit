# Asset provenance and permitted project scope

This is Philip's private project toolkit; it does not grant blanket public redistribution rights to all contents.

- mascot/rig: 36 registered raster sprites derived from Philip's supplied LiplnwZa model and image-generated pose/mouth artwork created for this project, then locally registered in Pilot002 v3. Reuse for Philip's requested content and team tests. Treat source character art as owner-controlled; do not sell a mascot pack or publish raw assets without owner approval.
- mascot/mouth_rig: six original poses and six clean plates based on Philip's supplied LiplnwZa character; generated/edited for this project on 2026-10-20 and included to render the mouth animation offline. Use only for Philip's requested content and team tests. Treat all raw character art as owner-controlled; do not sell or publish the raw assets without owner approval. The legacy sprites above are retained for comparison and are not used by the v0.2 renderer.
- fonts/Prompt-Bold.ttf: Prompt font; exact OFL text supplied in fonts/OFL.txt. Retain this notice when distributing font files.
- illustrations/red_car.png: original programmatically drawn generic car from Pilot002. No Tesla logo or actual footage. Use as illustration, not proof of a real event.
- examples/benchmark15/voice.wav: edited excerpts of the voice file supplied by Philip, according to audio_edits.json. Philip authorized public distribution of this benchmark voice file in this repository, including its git history, by decision on 2026-10-26. This permission covers distribution of this file only; it is not permission to clone Philip's voice, to train voice models on it, or to publish any other voice. Original long voice stays outside this kit.
- SFX: generated locally by renderer/kit.py, not sampled from other creators.
- No Warodom media, likeness, logo, voice, course files or downloaded third-party stock is included.

For any new stock file, retain the item's actual license and check source redistribution separately from permission to use it inside a finished video.
